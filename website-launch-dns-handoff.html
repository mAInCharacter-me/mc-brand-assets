2. DNS rule

DNS points the custom domain to the website host, not to GitHub. GitHub Pages hosts brand assets. Vercel (or the selected production host) hosts the website.

  • Confirm the production Vercel project and custom domain.
  • Use the exact DNS records supplied by the hosting provider.
  • Do not invent A, CNAME, TXT, or redirect values.
  • Confirm root-domain and www behavior before changing records.
  • Preserve existing email records unless explicitly required.

3. Pre-DNS checklist

  • □ Production build passes and the correct Vercel project is identified.
  • □ Navigation, CTAs, booking links, client login, calculator, and portal links are tested.
  • □ Favicon, social preview, page titles, descriptions, and canonical URLs are present.
  • □ Mobile, keyboard, contrast, and basic accessibility checks pass.
  • □ Forms, scheduling, analytics, privacy, and terms links are tested.
  • □ No staging URLs remain in customer-facing copy or metadata.
  • □ Logo, icon, favicon, OG image, and token links resolve.
  • □ Rollback plan exists with previous DNS values and deployment URL.
  • □ Authorized domain owner applies DNS; HTTPS and redirects are verified afterward.
