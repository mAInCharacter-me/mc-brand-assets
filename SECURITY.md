# Reporting impersonation, misuse or a security problem

## Official channels

mAInCharacter publishes from these places and no others:

| Channel | Address |
|---|---|
| Website | https://main-character.me |
| GitHub organization | https://github.com/mAInCharacter-me |
| Email | addresses ending in `@main-character.me` |

A site, account, repository, email or document that carries the mAInCharacter
name or marks and is not on this list is not ours.

## What to send

Write to geeks@main-character.me with the URL, a screenshot, and the date you
saw it. For a repository or package, include the full name and the commit or
version. We acknowledge reports within two business days.

## What we never do

We do not send unsolicited invoices, payment links, password resets or
credential requests from any domain other than `@main-character.me`, and we do
not ask for payment through third-party chat.

## Security issues in this repository

If a file in this repository or at one of its published URLs executes code,
loads an external resource, or differs from the SHA-256 recorded in
`manifest.json`, report it to the same address with the subject line
`security`. Do not open a public issue for a security report.
